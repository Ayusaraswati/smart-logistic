# GeoCareer & GIS Industrial Hub

Studi kasus interaktif dan dashboard wawasan karir berdasarkan materi kuliah praktisi *Informatics Practitioner Lecture Series* Universitas Bengkulu dengan tema **"Career and Competition in Industrial Era with GIS"** oleh Bapak Widi Primadeva (Asset Management GIS Analyst at City Care Property, Selandia Baru).

## 🚀 Live Demo
Akses website secara online melalui tautan GitHub Pages:
[https://ayusaraswati25.github.io/gis-career-hub/](https://ayusaraswati25.github.io/gis-career-hub/)

## 🛠️ Fitur & Modul Utama
- **Wawasan & Strategi Karir IT di Bidang GIS:** Menjelaskan keunggulan kompetitif lulusan Teknik Informatika (*one step ahead* sebagai GIS Developer).
- **Standar Kompensasi Global:** Informasi estimasi kisaran gaji industri di Selandia Baru (*New Zealand*).
- **Simulasi AI & Workflow Cloud GIS:** Fitur interaktif untuk mensimulasikan arsitektur data *Cloud GIS*, *Machine Learning* deteksi *blind spot* radio, dan pemrosesan *Feature Manipulation Engine* (FME).
