# Smart Logistics & Courier Routing Hub

Aplikasi web interaktif berbasis studi kasus nyata layanan pesan-antar dan kurir logistik perkotaan untuk menghitung estimasi rute tercepat, jarak tempuh, serta kalkulasi biaya pengiriman secara *real-time*.

## 🛠️ Fitur Utama Aplikasi
- **Pengaturan Titik Penjemputan (*Pickup*):** Memilih lokasi asal pengiriman dari berbagai titik strategis (Mall, Restoran/Cafe, Gudang Transit).
- **Input Alamat Tujuan Fleksibel:** Kolom teks interaktif bagi pengguna untuk memasukkan alamat tujuan pengantaran secara bebas.
- **Pilihan Layanan Kurir:** Mendukung berbagai kategori layanan mulai dari *Instant (Motor)*, *Same Day*, hingga pengiriman *Cargo* besar.
- **Kalkulator Estimasi Instan:** Menghitung perkiraan jarak tempuh (kilometer), estimasi waktu tiba (menit), dan total biaya ongkos kirim secara otomatis.
- **Referensi Tarif Harian:** Informasi ringkas daftar harga standar layanan kurir di perkotaan.
